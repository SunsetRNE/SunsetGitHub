C+ 方案。保留 C 版的主视觉，但把页面做得更像真实可交付的 Android Profile 页，而不是单纯展示稿。

落地建议

1. Profile Hero在 `fragment_profile.xml` 第一张 MaterialCardView 内增加 cover View，头像使用负 margin 或 FrameLayout 叠放。保留 `image_profile_avatar`、`text_profile_name`、`text_profile_login` 等 id。
2. 概览卡合并把当前“账号概览”和“语言分布”合并在同一个卡片中，减少页面纵向碎片。语言条仍复用 `container_profile_language_bar` 和 legend 动态填充。
3. 贡献区`ContributionCalendarView` 保持不重写，主要调整外层标题、说明、legend 和 activity overview 的容器样式。
4. 仓库条目优化 `ProfileFragment` 中动态创建仓库 item 的布局：仓库名蓝色、Owner 弱化、描述最多两行、语言/星标/Fork 在底部一行。
5. 首轮验证建议实现后跑 `./gradlew assembleDebug`，并重点检查 360dp 宽度、深色模式、空资料、无语言、无贡献、仓库名超长等情况。
