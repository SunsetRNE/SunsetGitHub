V5 主页面。红框中的两个按钮已经从资料卡内移除，简化为右上角工具栏动作；资料卡高度下降，统计区更快露出。

本次调整

1. 去掉资料卡内大按钮

`打开 GitHub` 和 `刷新资料` 原本占据一整行且割裂资料信息。V5 把它们移到顶栏右侧，资料卡只负责展示身份与核心状态。

2. 顶栏动作简化

右上角使用三个小动作：`GH` 打开 GitHub、`↻` 刷新资料、`⋯` 更多操作。落地到 Android 时可替换为 vector drawable 图标。

3. 首屏高度释放

移除按钮行后，资料卡高度减少，关注者/正在关注/仓库统计更靠上；概览卡可以更早进入视野。

4. 实现建议

`fragment_profile.xml` 中删除 Hero 内两个 MaterialButton；在 Activity 顶栏菜单或 ProfileFragment 自己的 toolbar 区域增加两个 action item。
