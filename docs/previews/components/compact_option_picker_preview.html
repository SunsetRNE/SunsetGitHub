选择器渲染方向

这版将系统 Spinner 替换为点击式输入框 + 居中弹窗。弹窗高度受控，内部滚动，长列表不会像截图那样铺满屏幕。选中项使用黑底白字，和当前新建仓库页面的黑色主视觉一致。

统一位置：两个选择器都从屏幕中部弹出，不再跟随 Spinner 锚点乱飘。
统一尺寸：最大高度约 70%，列表内部滚动。
可复用：后续可抽成 CompactOptionPickerDialog，和 CompactBlackDialog 同一套资源体系。
