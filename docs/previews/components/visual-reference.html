设定项映射

调整 Android 默认视觉时优先看这些资源。

  • @color/github_canvas页面背景、Activity 根背景、暗色模式基底。
  • @color/github_surfaceToolbar、卡片、弹窗、系统栏、底部导航背景。
  • @color/github_accent主品牌色、选中导航、PrimaryButton、链接、Dialog 按钮。
  • @style/Widget.SunsetGitHub.Material.GlobalButton全局默认 MaterialButton，目前黑底白字。
  • @style/Widget.SunsetGitHub.Material.PrimaryButton明确主操作按钮，使用 accent 色。
  • @style/Widget.SunsetGitHub.Material.Card默认卡片：surface 背景、12dp 圆角、1dp border、0dp elevation。
  • @style/Widget.SunsetGitHub.Material.TextInput默认输入框：OutlinedBox、10dp 圆角、muted hint。
  • @style/Widget.SunsetGitHub.Material.BottomNavigation底部导航背景、item icon/text tint、label 模式。
  • @dimen/card_corner_radius默认卡片圆角，当前 12dp。
  • @dimen/page_horizontal_padding页面横向 padding，当前 8dp。

快速调色区

可以先改下面这些 CSS 变量预览方向，再同步到 Android XML 资源。

:root {
  --canvas: #ffffff;              /* @color/github_canvas */
  --surface: #ffffff;             /* @color/github_surface */
  --border: #d0d7de;              /* @color/github_border */
  --text-primary: #24292f;        /* @color/github_text_primary */
  --text-secondary: #57606a;      /* @color/github_text_secondary */
  --text-muted: #6e7781;          /* @color/github_text_muted */
  --accent: #0969da;              /* @color/github_accent */
  --success: #1a7f37;             /* @color/github_success */
  --attention: #bc4c00;           /* @color/github_attention */
  --danger: #cf222e;              /* @color/github_danger */
  --done: #8250df;                /* @color/github_done */
  --chip-bg: #eff2f5;             /* @color/github_chip_background */
  --button-global: #000000;       /* GlobalButton backgroundTint */
  --card-radius: 12px;            /* @dimen/card_corner_radius */
  --button-radius: 8px;           /* GlobalButton / PrimaryButton cornerRadius */
  --input-radius: 10px;           /* TextInputLayout box corner radius */
}
当前默认设计含义修改建议
colorPrimary = github_surface顶栏/系统栏更像内容容器，而不是强品牌色。若想更品牌化，可只改 toolbar 背景，避免全局 primary 影响 Dialog、Ripple 和系统控件。
GlobalButton = black接近 GitHub 的高对比默认操作按钮。若觉得过重，可改为 outline 风格或使用 github_accent。
Card elevation = 0dp以边框分层，符合 GitHub Primer 风格。若要 Material 阴影感，提高 elevation 时也要降低边框存在感。
page_horizontal_padding = 8dp移动端信息密度较高。若页面显拥挤，可尝试 12dp 或 16dp，并同步卡片内边距。
