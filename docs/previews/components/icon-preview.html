SunsetGitHub 图标候选预览

这是基于 Google 官方 Material Symbols Rounded 做的本地预览页。优先看图标在小尺寸下是否清楚， 以及是否适合和“日落 / GitHub 客户端 / 代码仓库”三个意象结合。

官方库：fonts.google.com/icons 建议风格：Material Symbols Rounded 推荐背景：橙紫日落渐变

结论

我建议最终用 code 作为前景符号，配橙紫日落渐变背景。 这个方案最像一个独立品牌，而不是直接借 GitHub 标志；同时桌面图标、启动图标、小尺寸状态下都比较清楚。 如果你想更强调“仓库浏览”，第二选择是 folder_open。
