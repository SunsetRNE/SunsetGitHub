关于加载骨架

  • 骨架必须模拟最终布局：风险卡、三格指标、列表行都占位。
  • 不要只放几条横线，否则加载完成会明显跳动。
  • 只在首屏初次加载用骨架；局部刷新用小型 progress 或行内状态。
  • 骨架文案不可见，避免闪烁中英文文本。

V3 缺的东西

V3 的信息都在，但没有优先级。V4 用顶部 risk strip 把页面从“状态清单”变成“安全处理入口”。
