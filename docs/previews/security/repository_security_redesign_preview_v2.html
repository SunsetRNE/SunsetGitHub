这版比 V1 多解决的问题

  • 不再只是把截图排好看，而是把 Security 变成可操作工作流。
  • 把 GitHub 仓库页顶部导航也放进页面，明确它是仓库子页，不是孤立信息页。
  • 增加告警详情底部面板，覆盖用户点击警报后的下一屏。

涉及页面与组件

RepositorySecurityFragment主页面。承载概览、告警列表、配置、空态、错误态。
fragment_repository_security.xml建议改为静态骨架：Hero、feature container、tabs、filter row、alerts container。
RepositorySecurityAlertDetailFragment可保留独立详情页；移动端也可用 BottomSheet 样式承接快速查看。
RepositorySecurityViewModel数据结构基本够用。需要补充 UI 映射：status severity、action hint、raw debug detail。
strings_formal.xml新增短文案，避免直接展示接口英文错误和 docs URL。

可落实路线

阶段 1：不改接口，只改呈现

把 probes 渲染为 feature card，把 alerts 渲染为 GitHub 风格列表，把 403/404 转成受限 notice。

阶段 2：补交互

加搜索框、筛选 chip、点击告警进入详情，保留现有 load more。

阶段 3：补配置入口

对 disabled / inaccessible / no analysis 提供打开 GitHub 设置、查看文档、检查 Token 权限。
