创建 GitHub Token

应用不会展示长链接，点击按钮即可拉起浏览器打开 GitHub 官方 Token 页面。

1
打开 GitHub Token 页面使用浏览器登录 GitHub，并进入 Personal access tokens 设置。
2
选择权限至少需要读取用户信息；仓库浏览、文件编辑、Issues 等能力需要对应权限。
3
复制 TokenToken 只会显示一次。复制后回到应用点击“我已获取 Token”。
建议权限

读取用户信息、仓库读取；如需上传/编辑文件，请授予仓库写入；如需 Issues/PR，请授予对应权限。

安全提醒

Token 相当于账号授权凭据。不要分享给任何人。应用会将 Token 加密保存在本机。
