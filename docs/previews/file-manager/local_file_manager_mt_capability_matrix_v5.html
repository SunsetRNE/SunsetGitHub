MVP 分层建议

第一层 P0：撤回彩色底栏、统一 MT 风格基础 UI、把 ArchivePane 做成真实右窗格。
第二层 P1：做 OpenWithToolGrid、APK 信息/签名校验、脚本执行确认、XML/文本入口。
第三层 P2：Dex/Arsc/Jar/Class/SVG/点九/对比/签名导入等工程工具逐个补。

现在确实是一大堆功能，但不能一次性全塞进 Fragment；需要从“文件管理器”拆成“文件浏览内核 + 类型工具注册表 + 专项工具模块”。

实施计划备忘录

阶段目标必须产出验收点
P0-1 UI 回正撤回彩色圆角底栏，恢复 MT 参考风格。52dp 灰白纯图标底栏；朴素多选底栏；文件操作 Sheet 统一为灰块网格。默认态、选中态、更多菜单、Sheet 均不再出现彩色卡片化视觉。
P0-2 弹窗基础设施解决长路径溢出、按钮遮挡、内容裁切。FileManagerInfoDialog / FieldValueTable / OperationProgressDialog / ConflictDialog。路径、URI、失败详情可自动换行；弹窗超高时内部滚动；底部按钮永远可见。
P0-3 ArchivePaneZIP/APK/APKS 内部结构直接进入右窗格。ArchiveSidePaneController；内部 .. 导航；内部文件预览；嵌套 zip 缓存进入。双栏点击压缩包时，对侧显示 archive!/innerPath 列表；单栏时当前列表进入内部结构。
P1-1 OpenWithToolGrid按文件类型分发工具能力。FileToolRegistry、FileToolDescriptor、OpenWithToolGridDialog。文本、图片、音视频、zip/apk、xml、dex、arsc、jar、class、sh 等能显示不同工具入口。
P1-2 APK 工具提供事实信息和工程工具，不替用户判定风险。ApkInspector、ApkInfoDialog、权限/组件/签名/加固/导出报告入口。APK 信息弹窗无“危险软件”判定章，只展示签名校验、加固识别等事实。
P1-3 脚本工具Linux/sh 脚本编辑与执行确认。ScriptExecutionController、执行设置、root 风险确认、输出日志。执行前必须显示工作目录、root 状态、超时、环境变量；可取消/查看日志。
P2 工程工具扩展逐步补 Dex/Arsc/Jar/Class/SVG/点九/对比/签名导入。各专项工具模块，先浏览和导出，再考虑编辑。每个工具独立模块注册到 FileToolRegistry，不膨胀 LocalFileManagerFragment。

架构红线：LocalFileManagerFragment 只保留生命周期、导航和事件分发；文件浏览内核、类型工具注册表、专项工具模块、弹窗渲染器必须拆开。任何新能力先注册为 FileToolDescriptor，再决定是否进入 Sheet / Popup / OpenWith 面板。
