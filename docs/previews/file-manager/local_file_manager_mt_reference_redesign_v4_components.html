V4：组件拆分稿，而不是继续堆整机截图

你指出的问题是准确的：V3 仍然有大量“整体场景截图式拼装”，没有把 MT 风格里的组件规范拆出来；并且冲突 / 进度弹窗出现了文本溢出、不自动换行、遮挡动作按钮这种实际落地会翻车的问题。V4 将组件单独展示，重点修正弹窗排版、换行、滚动、字段宽度、底部按钮区。

弹窗原则
字段列固定，值列 minmax(0,1fr)，长路径必须 anywhere 换行。
列表原则
文件名单行省略，元信息单行省略，点击后才进入详情。
压缩包原则
ZIP/APK 内部结构用右窗格列表，不用弹大说明。
授权原则
无权限目录可以显示空态授权，但 root 模式另行设计，不混在普通 SAF 里。
