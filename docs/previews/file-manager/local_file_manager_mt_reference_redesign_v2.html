落地原则修订

  • 颜色只保留文件类型必要色：文件夹黑、代码蓝、APK红/绿名、压缩包棕；功能区与弹窗不用多彩语义块。
  • 弹窗采用参考图的白色 Material 朴素信息表：标题大字、左字段右值、底部文字按钮。
  • 压缩包 / APK 浏览不是弹 Toast，也不是独立大页，而是优先在另一侧窗格展示内部结构；单栏时可用当前列表替换进入。
  • 更多操作 Sheet 用灰色小方块承载高频操作，避免上一版设计系统式彩色卡片。
  • 这份稿是用于替换上一版方向的 V2 设计基准，后续 UI 代码应以本稿和 docs/file-manager-module-preview.html 为准。
