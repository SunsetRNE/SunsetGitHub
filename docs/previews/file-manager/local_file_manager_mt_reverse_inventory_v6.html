1. 受限目录访问策略

  • 添加其它应用目录
  • 为目录所属 APP 注入文件提供器
  • 授予 ROOT 权限后访问
  • Shell / Shizuku 访问 Android/data
  • Files 程序版本不支持授权时的降级提示
逆向证据：字符串包含“① 为该目录所属 APP 注入文件提供器”“② 为 MT 授予 ROOT 权限后再访问”“开启 Shell 权限后无需授权也可访问该目录”。

2. APK 安装策略

  • 安装前验证签名和版本号

  • 签名不一致提示
  • APK 安装防自动删除
  • 需要签名后再安装
逆向证据：“使用 Shizuku 安装 > 使用 Dhizuku 安装 > 使用 Root 安装 > 调用系统安装”。
