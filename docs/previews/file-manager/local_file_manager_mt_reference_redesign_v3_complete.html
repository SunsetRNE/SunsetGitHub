                        16 底层架构拆分边界：避免 Fragment 继续膨胀

                        00:06◷ ◢◢ 48
                        落地拆分
                        Renderer / Dialog / TargetPicker / ArchivePane

                        1. LocalFileManagerActionSheet
                        2. LocalFileManagerPropertyDialog

                        原则：
                        Fragment 只做生命周期和导航；UI 渲染与弹窗从 Fragment 抽出；压缩包右窗格与真实目录窗格共用 EntryAdapter。

                        V3 定稿要点

                        • 上一轮已经落地的彩色圆角底栏应撤回，恢复为参考图式 52dp 灰白纯图标底栏；多选态可以带短文字，但仍保持灰白朴素。
                        • 弹窗采用 Android 朴素白色信息表，禁止彩色卡片化；按钮放底部，蓝色文字按钮即可。
                        • 压缩包/APK 的“发挥作用”关键是右窗格内部结构浏览：选中 ZIP/APK 后，另一侧窗格展示 archive!/path 内容；内部文件直接预览，内部 ZIP 继续进入。
                        • 目标选择、冲突、进度、错误状态都已补齐为可落地组件，不再只是功能描述。
                        • 后续代码落地顺序建议：先撤回彩色底栏 → 恢复 MT 底栏与多选态 → 抽出朴素 Sheet → 做属性/APK 信息弹窗 → 做 ArchiveSidePaneController。
