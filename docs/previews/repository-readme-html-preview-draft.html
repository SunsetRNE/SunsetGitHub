README.md

SunsetGitHub

一个为移动端压缩重绘的 GitHub 客户端。仓库详情页优先保留 GitHub 网页的信息结构，再按手机屏幕做密度和操作入口调整。

Kotlin Jetpack Compose Markdown HTML GitHub API

功能目标

  • 根目录文件列表与 README 在同一条浏览流里。
  • README 按 HTML/markdown-body 渲染，支持图片、表格、代码块和任务列表。
  • 发布版、语言比例、贡献者、许可证作为仓库侧栏信息下沉到 README 后。
Design note这版更贴近实际仓库详情：先代码，再 README，再仓库元信息。

示例代码块

RepositoryDetailScreen(
    sections = listOf(
        BasicInfo,
        RootContents,
        Readme,
        Releases,
        Languages,
        Contributors,
        License
    )
)
