组合规则

组合处理原因
Docked + Glass / Acrylic可用但不推荐，优先降级到 Solid 或 TonalDocked 是占位 surface，强玻璃容易造成底色断层和视觉噪音
Floating + Solid可用，作为低端或高对比 fallback没有玻璃质感，但层级稳定
Compact + Large density冲突，Compact placement 强制 IconOnly 或 IconLabel高度不足，label 容易裁切
Dark + Glass独立 token，不复用浅色透明度深色玻璃需要更弱高光、更强边界
RepositoryTemp + Main menu无效组合临时分区只属于仓库菜单
Hidden + 任意 material/menu不渲染 material，不发布 inset隐藏态不应该保留视觉副作用
