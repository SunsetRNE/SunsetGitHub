细节态为什么必须纳入变体Android 实现建议
Badge / unread通知、Issues、Actions 失败态都会需要角标，玻璃上角标对比度要单独处理Menu item model 增加 badge 字段，renderer 负责位置和颜色
Disabled item未登录、权限不足、加载中等场景不能只隐藏入口item state 支持 enabled=false，点击事件不派发
Long label中文、英文长词、无障碍字体会导致 label 裁切Compact 自动 IconOnly；Regular 使用 ellipsize
Pressed / selected玻璃材质上选中态太淡会不可见，太重会脏activeAlpha 作为 token，而不是硬编码颜色
Token 调节不同机型、主题、手势栏高度会改变最优尺寸RenderPlan 输出 height/radius/margin/inset
