资源层建议

资源当前观察建议
bg_bottom_nav_docked直接使用 github_surface，合理保留，作为 Solid Docked 变体
bg_bottom_nav_floating使用 github_floating_nav_background + border + radius作为 Floating Frosted 的基础，不要过度彩色化
nav_item_tint未选中/禁用为 black，夜间可能不可读改为 github_text_secondary / github_text_muted，checked 使用 github_accent
Glass项目没有真玻璃资源新增 material renderer token，不替换现有 drawable 语义
结论：最适合本项目的不是花哨 acrylic，而是 GitHub 风格的轻玻璃：白天接近 #EBFFFFFF，夜间接近 #EB161B22，加 1dp border、轻阴影和独立深色 tint。
优先修正：深色模式 item tint 应先处理，否则任何深色导航栏预览都会和真实实现脱节。
