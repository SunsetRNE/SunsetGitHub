推荐内置渲染变体

Default

Docked Solid

稳定默认态。用于未开启悬浮、低端设备、玻璃降级、无障碍高对比场景。

Preferred

Floating Glass

主要目标态。用于仓库页和主导航页的悬浮导航，强调底色连续、轻量透明和高光边界。

Fallback

Floating Frosted

假玻璃降级态。没有真实 backdrop blur，但通过半透明、stroke 和 shadow 维持视觉层次。

Contextual

Compact Floating

键盘、横屏、低高度或密集页面使用。优先保留图标，label 可隐藏。

Theme

Dark Glass

深色主题不能直接套浅色玻璃，需要更低透明度、更弱高光和更强边界。

Accent

Tonal Surface

非玻璃的品牌/状态变体。适合高对比、低性能或需要明确页面身份的场景。

落地建议

现在方案应该从“写组件架构”转为“实现渲染变体”。第一刀建议做：`AppNavigationBarLayout` 接收一个 `RenderPlan`，先能渲染上面这些变体中的 `Docked Solid`、`Floating Glass/Frosted`、`Compact Floating` 和 `Hidden`。

玻璃先按 FakeGlass/Frosted 实现，真实 RenderEffect 或 snapshot blur 作为后续 material renderer，不影响 placement/menu/density。
