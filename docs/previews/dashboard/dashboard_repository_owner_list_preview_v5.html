A5：去掉“继续开发”角标，把工作台做成可收容组件

你说得对，卡片右上角“继续开发”和黄色 Issue badge 重复，而且会挤压收藏按钮，是过度设计。A5 保留“首个卡片高亮边框”即可，不再贴角标；工作台改成可折叠/可收起的组件。

建议定稿原则
  • 删除卡片级“继续开发”角标。
  • 工作台默认显示轻量摘要，不强迫占据大面积。
  • 展开态才显示 4 个统计块。
  • 折叠按钮放右侧，状态清晰：⌄ 展开 / ︿ 收起。
  • 如果用户关闭工作台，下次进入可记忆折叠状态。
