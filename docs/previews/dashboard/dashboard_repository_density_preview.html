仓库页信息密度改造预览

目标是在现有 SunsetGitHub / Primer 风格上压缩卡片高度、减少大留白，并把语言构成从“单语言文本”升级为可扫读的比例条。下面给出三种可选密度：推荐默认使用“平衡紧凑卡片”，列表很长时切换“极速列表”。

Compose LazyColumn 语言比例条 卡片高度约 -28% ~ -45% 减少阴影和嵌套 稳定 key + 预排序

实现建议

  • 列表项保持纯 Compose，避免每项 AndroidView / 复杂 Shape。
  • 语言颜色和百分比在 ViewModel 层预计算，UI 层只绘制。
  • 描述默认 1～2 行，完整信息进入详情页。
  • 排序/搜索结果使用 remember 缓存，避免每次重组重复 filter + sort。
  • 加载语言接口并发限流，先显示基础仓库，再渐进补语言条。
