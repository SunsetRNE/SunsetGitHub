A8：精修整体比例，而不是继续加内容

比例怪的核心通常是：顶部空白太大、搜索框和卡片尺度不在同一个系统、卡片内文字层级跨度过大、排序菜单太宽太粗。A8 把页面节奏收敛到 8dp 网格，做三种强度。

  • 标题区不再和搜索区拉开巨大距离。
  • 搜索 42dp、卡片 100~120dp，比例统一。
  • 卡片保留细语言线和语言条，但压低存在感。
  • 菜单换白底圆角，和当前淡紫大菜单相比更精致。
