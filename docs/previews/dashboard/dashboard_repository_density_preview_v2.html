A 方向二次打磨：解决仓库名断行和视觉层级

你圈出来的问题本质是 owner/repo 作为一个长字符串时，换行点不可控，导致“SunsetRNE/”占据视觉焦点，真正的仓库名反而被切断。A2 把 owner 降级、repo 升级，并提供 3 种标题策略。

推荐结论
  • 默认用“分层标题”：owner 小字，repo 大字。
  • 长仓库名允许 repo 自身换 2 行，而不是 owner/repo 一起乱断。
  • 语言图例只显示前 2～3 个，更多进详情页。
  • 描述默认 1 行；列表性能优先。
