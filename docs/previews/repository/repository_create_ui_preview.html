新建仓库 UI 包裹与弹窗效果预览

此文件用于预览“新建仓库”页面的视觉方向：减少灰色弱对比区域，改用黑色作为主按钮、强调边框、顶部包裹和弹窗头部；同时通过分组卡片、双列配置、紧凑控件减少页面纵向长度。

  • 页面包裹：顶部说明区改为黑色渐变 Hero 卡片，表单统一放入圆角白色容器，外层保留轻阴影与细边框。
  • 灰色转黑色：主操作按钮、选中态边框、返回按钮、勾选态、弹窗确认按钮均使用 #0d1117 黑色渲染，提升决策焦点。
  • 结构紧凑：将可见性改为左右分段卡片，将 gitignore / license 改为双列，Issues / Projects / Wiki 改为三列 chip 式选择。
  • 弹窗效果：增加半透明黑色遮罩、圆角白色对话框、黑色标题头、阴影抬升与黑色确认按钮，视觉上更像独立浮层。
