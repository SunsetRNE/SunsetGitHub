方案 B：目录标题栏紧凑动作

把两个功能固定在“根目录”标题右侧，和当前内容区强绑定。优点是节省纵向空间；缺点是小屏文字需要折叠为图标或短文案。
建议实现：宽屏显示 “Go / New”，窄屏显示图标；点击 New 后弹出 bottom sheet，列出 Create new file、Upload file、Create folder。
