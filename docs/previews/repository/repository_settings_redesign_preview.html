二、落地拆分建议

从当前截图出发，优先做视觉重排；复杂设置暂时做入口，不一次性扩大范围。

第一阶段：只改布局和样式

保留现有数据加载、保存逻辑和字段模型。把页面拆成：顶部摘要卡、基础信息卡、可见性卡、仓库资料卡、功能开关卡、合并策略卡、二级入口卡、危险区卡。这个阶段最稳，可直接对照截图替换 XML。

低风险最快可落地不改 API

第二阶段：保存体验增强

新增“未保存更改”状态、底部保存栏、变更摘要弹窗。保存成功后刷新仓库缓存；失败时保留草稿并提供重试。
